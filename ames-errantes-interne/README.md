# Espace interne Âmes errantes

Cette interface fait partie de la plateforme commune située dans le dossier parent.
Consulter [le guide commun](../README.md) pour démarrer Docker, se connecter, sauvegarder et travailler avec Claude.

Toute l’administration est ici : dossiers, tâches, animaux, photos, demandes, suivi, réglages, sauvegardes et comptes. La connexion et le changement de mot de passe passent par cet espace uniquement.
Les données sont dans PostgreSQL, via `../packages/core`. Les écrans et routes de gestion sont propres à cet intranet et ne dépendent pas du code du site public.
Les anciens fichiers SQLite et imports Spaces sont des archives, conservées pour la migration uniquement.
